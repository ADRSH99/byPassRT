```text

        ↓

        ↓

        ↓
AF_XDP Backend
        ↓
```

### Key Idea:

* **Kernel only provides a fast path via XDP**

# 3. 🔧 Core Components

---

## 3.1 AF_XDP Backend (I/O Engine)

This is the foundation of your system.

### Responsibilities:

* Create and bind AF_XDP socket
* Configure UMEM (shared memory region)
* Manage rings:

  * RX ring
  * TX ring
  * Fill ring
  * Completion ring

### Implementation Steps:

1. Create XDP socket (`xsk_socket__create`)
2. Allocate UMEM
3. Register memory with kernel
4. Attach XDP program to interface
5. Bind to NIC queue

---

## 3.2 Packet Buffer System (mbuf-lite)

Simplified version of DPDK’s mbuf.

### Structure:

```c
struct lite_mbuf {
    uint8_t *data;
    uint16_t data_len;
    uint16_t buf_len;
    uint64_t timestamp;
};
```

### Features:

* Fixed-size buffers
* No dynamic allocation in fast path
* Preallocated memory pool

---

## 3.3 Memory Pool

### Design:

* Allocate large contiguous memory region
* Divide into equal-sized buffers
* Maintain free buffer ring

### Operations:

* `alloc()` → get buffer
* `free()` → return buffer

---

## 3.4 Lock-Free Ring Buffers

Used for:

* RX queue
* TX queue
* Free buffers

### Basic Structure:

```c
struct ring {
    uint32_t head;
    uint32_t tail;
    uint32_t size;
    void *entries[];
};
```

### Phase 1:

* Single Producer / Single Consumer (SPSC)

### Later:

* Multi-core support

---

## 3.5 Polling Engine

Core execution loop:

```c
while (1) {
    n = rx_burst(rx_queue, pkts, BURST_SIZE);

    for (int i = 0; i < n; i++) {
        process(pkts[i]);
    }

    tx_burst(tx_queue, pkts, n);
}
```

### Features:

* Batch processing
* No interrupts
* CPU affinity (optional)

---

## 3.6 Minimal API Layer

Expose simple interface:

```c
int lite_init(const char *ifname);
int lite_rx_burst(struct lite_mbuf **pkts, int max);
int lite_tx_burst(struct lite_mbuf **pkts, int count);
void lite_free(struct lite_mbuf *pkt);
```

### Design Goals:

* Minimal
* Easy to use
* Abstracts AF_XDP complexity
